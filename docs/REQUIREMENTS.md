# Матрица приёмки v1

Источник — `SPEC.md`, раздел25. Одна проверка может покрывать несколько требований. Автоматические сценарии обращаются к реальному серверу и PostgreSQL, не к заглушкам всего API.

| Требование   | Экран / реализация                                   | Подтверждение                                                                                                                                                            |
| ------------ | ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| AUTH-01/02   | `/login`, `server/auth`, auth allowlist, DB throttle | `acceptance.spec`: вход, старый cookie после logout, регистрация404, неверный пароль и429                                                                                |
| ACL-01/02/03 | `server/access`, scoped сервисы, `modules/files`     | `workflows.spec`: два аккаунта, чужие course results/roster/files/project/achievement/request, общий курс, finance/private DTO; `calendar.spec`: чужой источник и export |
| HOME-01      | `/`, HomeCalendar, NextClass                         | Seed с будущими днями, безопасные снимки двух тем; браузерный маршрут главная→календарь                                                                                  |
| CAL-01       | `/calendar`, URL state, day/week/month               | `calendar.spec`: три представления/reload; `acceptance.spec`: следующий период/сегодня                                                                                   |
| CAL-02       | SchedulePicker, saved schedules                      | `acceptance.spec`: поиск ПИ-22, сохранение, сравнение и reload                                                                                                           |
| CAL-03/04    | Calendar, temporal checks, personal service          | Unit раскладки и исключения будущих/отменённых; API privateCRUD/sequence/foreign denial; ICS all-day/cancel                                                              |
| ICS-01/02    | preview→worker→commit                                | `calendar.spec`: повтор/перенос/replace/expiry/owner; `ics.test`: DST/floating/all-day/RRULE/EXDATE/limits/unsupported/sourceinterval                                    |
